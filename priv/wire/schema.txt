# The hireme wire schema. One source for Elixir (HiremeWeb.Packet, @external_resource),
# Rust (native/wire build.rs) and, through the kernel, TypeScript. schema_hash = FNV-1a-32 over
# this file's bytes, xor-folded to 16 bits (hi ^ lo); every frame header carries it.
#
# Frame: u32 len (whole frame incl. the 16-byte header, multiple of 8) | u8 kind | u8 flags |
# u16 schema_hash | u64 rev | body. Flags: 0x01 DEFLATE (body = u32 raw_len | u32 deflate_len |
# raw-deflate bytes | pad; inflated it is the plain body), 0x02 END (last frame of a burst),
# 0x80 AGENT (HELLO only: the credential is an API key).
# Table body: a sequence of  u16 table_id | u16 ncols | u32 nrows | col*ncols ;
# col := u16 col_id | u8 type | u8 0 | u32 byte_len | data | zero pad to 8 (8-aligned from frame start).
# Wire types: 1 u32 (day = days since 1970-01-01, time = unix seconds; none = 0xFFFFFFFF),
# 2 str ((nrows+1) u32 offsets from 0, then UTF-8; none = empty), 3 u64, 4 f64 (none = NaN).
# PATCH writes only the columns present; cards upsert by id; cards_gone deletes; the small tables
# (score, lanes, kv, roots...) are replaced whole when present. FOCUS carries one job (header rev =
# its focus rev) as the focus* tables; LINES upserts lines by ix (content-derived, stable across
# sessions). BOOT replaces the desk tables; a HELLO whose snapshot_rev is current gets an empty
# PATCH with END instead, which keeps everything. OP body: u64 op_id | u8 kind | u8 nfields |
# u16 0 | u32 target | (u16 len, utf8) * nfields, fields in the order the `op` line names them.
